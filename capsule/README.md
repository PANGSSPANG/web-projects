# 扭蛋

打开就随机甩给你一样东西（笑话 / 外语 / 知识点 / 书介绍），点一下换一个，专治无聊。

这是一个纯静态网页：单个 `index.html` 文件，无需安装依赖、无需构建，直接用浏览器打开即可使用。

## 使用

直接双击打开 `index.html`，或者用任意静态服务器托管（例如 `npx serve .`、`python -m http.server`）。

## 内容来源

内置了一批笑话、外语例句、知识点和书介绍，**无需任何配置，打开就能用**。

想要更丰富的实时生成内容，可选填 DeepSeek API key：

1. 点右上角齿轮打开设置
2. 粘贴你的 API key（在 https://platform.deepseek.com 获取）
3. key 只保存在本机浏览器的 localStorage 里，不会上传

填了 key 就用 AI 实时生成；不填（或清空 key）就自动退回内置内容库。

## 说明

- 内容类型：笑话、外文句子（原文 + 翻译 + 语种）、知识点、书介绍
- 盲抽，无选择；连抽不会连续出现同一类
- AI 提示词里已加防编造约束：知识点只出常识级事实，书只推荐真实存在的经典书
