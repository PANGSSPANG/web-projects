# 🍅 番茄钟 (Pomodoro Timer)

一个轻量的番茄工作法计时器，纯 HTML / CSS / JS，无依赖、无需构建。

## 功能
- 专注 / 短休息 / 长休息 三档模式，时长可自定义
- 环形进度条 + 标签页标题实时倒计时
- 时间到自动提示音（Web Audio）与浏览器通知
- 记录今日完成的番茄数（按天自动重置，localStorage 保存）

## 本地运行
直接用浏览器打开 `index.html` 即可。

## 发布到网页
把整个文件夹上传到任意静态托管即可：

- GitHub Pages / Vercel / Netlify / Cloudflare Pages
- 或把 `index.html`、`styles.css`、`app.js` 放到任意静态服务器 / 对象存储（如 OSS、COS）
